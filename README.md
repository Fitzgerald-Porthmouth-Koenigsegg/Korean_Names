# Korean_Names

韩国历史人物的汉字姓名列表。`konames.txt` 每行一个姓名，UTF-8 编码，无 BOM。

当前收录 360,098 个不同姓名字符串，具体版本、文件校验值及仓库差异见 `audit/release_manifest.json`。同名人物只保留一个姓名字符串，条数不是历史人物总数。

## 收录范围

以半岛政权人物及已在韩国定居任职者为范围。资料包括承政院日记、官方榜目、文谱及其他名录；依具体上下文区分完整姓名、官称、关系称呼及中国历史典故。独立韩国同名用例可以保留，不能只因与中国人物同名就删除。

采用当前已核资料的收录集合。完整但仍有疑似字的用户读法按项目约定保留，另存核查记录；无法辨认、缺字且无可靠对应的候选不凭空补全。

## 字形

终端采用项目明确的正形规则，例如儞→你、凖→准、彞→彝、槇→槙、黙→默。保留姓名中需要区分的原字，例如崙、濬、著、昪、昇、廸、樑、巖、鍊、譟。不能对整份名单再次无差别繁简转换，也不能按读音或字形相似擅自归并。

## 本版状态

已全量回查71个二、三字以“官”结尾的条目，保留66条有完整姓名用例者，移除5条官称。逐名依据见 `audit/guan_endings_v106.json`。

本轮已知回填、具名疑点和旧入库遗漏已结案，没有新的必填表。本版可作为当前收录集合发布；不表示所有文献的全部姓名都已找齐，也不表示所有姓名均已逐人完成身份考证或所有原书/OCR已经逐字校准。后续发现新证据仍可更正或补充。
